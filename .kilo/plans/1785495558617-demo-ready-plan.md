# RealtyAI Demo-Ready Plan

Goal: System real realtors can log into, scrape property listings, chat with Athena, see personalized dashboard data, and get daily briefings — all with multi-tenant data isolation.

## Decisions Made

- Full multi-tenant: each agent owns their leads, listings, memories, conversations
- Custom domain: `realty.indicationsmedia.com` must work
- All features: chat, scrape+import, daily briefing, contract analysis, calendar/showings, marketing
- No credit card, no OpenAI key needed for demo (free LLM path: opencode-zen)

## Deployment Strategy

1. Fix code → commit → push → `railway up --detach`
2. Wait for Railway build (2-5 min for code-only changes)
3. Test via curl before testing in browser
4. Vercel frontend deploys on push automatically
5. Custom domain configured manually in Wix and Vercel dashboards

## Validation Steps

After each phase, verify:
1. `curl` test against Railway backend

5. Chat with Athena: "give me my daily briefing"
